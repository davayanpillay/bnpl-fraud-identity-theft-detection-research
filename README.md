Machine Learning Methodologies for Detecting Identity Theft in Buy-Now-Pay-Later Fintech Systems

Postgraduate Diploma in Data Analytics — Research Project

This repository contains the Jupyter notebook used to evaluate Logistic Regression, Random Forest and Support Vector Machine models for financial transaction fraud detection.


Dataset

Credit Card Fraud dataset, available on Kaggle.

Link - https://www.kaggle.com/datasets/joebeachcapital/credit-card-fraud
